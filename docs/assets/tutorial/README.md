# 教程截图

本目录保存 README 图文教程使用的本地截图，来源为项目作者发布的[原始博客](https://linux.do/t/topic/2140889)。

维护规则：

- 使用两位数字前缀保持阅读顺序。
- README 使用相对路径引用，避免依赖外部 CDN。
- 云厂商、Cloudflare、New API 和客户端界面可能变化；截图用于定位功能，操作说明以 README 文字为准。
- 新截图不得包含有效密码、Token、OAuth 凭据、TLS 私钥或未公开的服务器信息。
- 替换截图时尽量保持文件名不变；新增截图应使用下一个可用编号，并同步检查 README 链接。

原博客页面包含 43 张教程截图和若干表情图标。仓库保存全部 43 张教程截图；表情图标使用 Markdown 或 Unicode 表达，不作为独立资源保存。
